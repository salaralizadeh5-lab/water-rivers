پایش منابع آب — V18

نسخه V18 شامل:
- GIS واقعی حریم و بستر بر اساس KMZ ارسالی
- لایه GeoJSON سریع برای نمایش در نقشه
- عوارض پرونده حریم و بستر
- ورود دستی WGS84 و UTM در ثبت نقطه
- پرونده زنده و خط زمانی
- هشدارهای هوشمند
- گزارش مدیریتی خودکار
- کاربران و امنیت محلی
- تنظیمات ظاهر، فونت، رنگ و GPS
- KML کامل برای Google Earth Pro شامل لایه حریم/بستر + نقاط + پرونده‌ها
- حفظ ساختار و داده‌های V17

نکته: کنترل دسترسی V18 محلی است. برای امنیت سازمانی واقعی و همگام‌سازی ابری چندکاربره باید Backend احراز هویت و API مشترک اضافه شود.
